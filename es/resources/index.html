Modelos para ejecutar localmente

Modelos descargables para experimentar en tu computadora. No hay un ganador universal: elegí según la tarea, el idioma y los recursos disponibles. Selección verificada el 22/10/2026; no es un ranking ni un catálogo exhaustivo.

Para empezar: instalá Ollama y elegí un solo modelo pequeño. Las versiones de 1–4B suelen exigir menos memoria que las de 7–8B. El equipo necesario depende también de la cuantización y la longitud del texto: el tamaño de descarga no equivale a la RAM necesaria. Las fichas enlazadas indican variantes y licencias. La inferencia local evita cargos por API, pero utiliza almacenamiento, memoria y electricidad. Estos comandos seleccionan modelos descargables, no variantes cloud. Probá primero ejemplos con respuestas conocidas; los ejercicios propuestos no son resultados de una evaluación propia.

01
QWEN · OLLAMA

Qwen3 · 4B

Modelo multilingüe disponible en Ollama. Con Ollama instalado, ejecutá: ollama run qwen3:4b. Descarga aproximada: 2,5 GB. Licencia Apache 2.0.

↗
02
META · OLLAMA

Llama 3.2 · 3B

Modelo de texto con soporte para español, inglés y portugués. Con Ollama instalado: ollama run llama3.2:3b. Aproximadamente 2 GB; revisar su licencia comunitaria.

↗
03
Mistral AI

Mistral · 7B

Texto general. Ejercicio sugerido: comparar resúmenes y extracción de información con Qwen sobre los mismos documentos.

ollama run mistral:7b
↗

Gemma 3 · 4B

Texto e imágenes. Ejercicio sugerido: describir gráficos y comprobar cada afirmación contra la imagen original.

ollama run gemma3:4b

Microsoft

Phi-4-mini · 3.8B

Modelo compacto con soporte multilingüe. Ejercicio sugerido: evaluar respuestas a preguntas con una rúbrica preparada antes de probarlo.

DeepSeek · distilled

Variante destilada para razonamiento. Compará respuestas y tiempos con un modelo general; una explicación larga no demuestra exactitud.
