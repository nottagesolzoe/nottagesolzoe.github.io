Models to run locally

Downloadable models to try on your computer. Choose by task, language and available resources. Selection checked on 22 October 2026; not a ranking or an exhaustive catalog.

Getting started: install Ollama and choose one small model. Versions around 1–4B usually need less memory than 7–8B versions. Requirements also depend on quantization and text length: download size is not RAM usage. Linked model cards list variants and licenses. Local inference avoids API charges but uses storage, memory and electricity. These commands select downloadable models, not cloud variants. Start with examples whose answers you know; the suggested exercises are not our benchmark results.

01
QWEN · OLLAMA

Qwen3 · 4B

A multilingual model available through Ollama. With Ollama installed, run: ollama run qwen3:4b. Download: about 2.5 GB. Apache 2.0 license.

↗
02
META · OLLAMA

Llama 3.2 · 3B

A text model supporting Spanish, English and Portuguese. With Ollama installed: ollama run llama3.2:3b. About 2 GB; review its community license.
