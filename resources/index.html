05 / TOOLS I RECOMMEND

A practical research toolbox.

Free or accessible tools for working with AI, data, automation, and reproducible research.

CURATED BY SOL

These are external tools I recommend, not products I created. Each one is here because it can remove friction from a real research task.

01
TRY + COMPARE LLMS

Hugging Face

Explore open models, datasets, and public demos. Useful for testing text classification, summarization, and multilingual workflows before writing a full pipeline.

MODEL EXPLORATION · DATASETS · DEMOS
↗
02
PROTOTYPE WITH AN LLM

Google AI Studio

Test prompts and structured outputs in the browser, then export starter code. A free tier is available, with limits and data-use conditions that should be checked before using sensitive material.

PROMPT TESTING · STRUCTURED OUTPUT · API
↗
03
RUN PYTHON IN THE BROWSER

Google Colab

A hosted notebook environment with no local setup. Useful for sharing reproducible examples, testing libraries, and running text or network analysis.

PYTHON · NOTEBOOKS · COLLABORATION
↗
04
AUTOMATE WORKSPACE TASKS

Google Apps Script

Use JavaScript to automate Sheets, Docs, Drive, Gmail, and Forms. Good for repetitive research administration, data collection, and lightweight internal tools.

AUTOMATION · GOOGLE WORKSPACE · JAVASCRIPT
↗
05
CLEAN MESSY DATA

OpenRefine

Inspect, transform, reconcile, and document changes to inconsistent tabular data without hiding the sequence of operations.

DATA CLEANING · RECONCILIATION · REPRODUCIBILITY
↗
06
TURN ANALYSIS INTO A TOOL

Streamlit Community Cloud

Publish a Python data app from a GitHub repository. Useful for small interactive research tools and public-facing prototypes.

DATA APPS · PYTHON · SHARING
↗
07
PUBLISH REPRODUCIBLE RESEARCH

Quarto + GitHub Pages

Combine code, narrative, citations, and figures in a website, report, or presentation, then publish the rendered output through GitHub Pages.

REPRODUCIBLE REPORTS · WEBSITES · SLIDES
↗

Use AI without losing the research trail.

Do not upload confidential material to a public service. Record the model, version, prompt, date, parameters, and human review. Treat generated labels and summaries as analytical outputs that require validation.
